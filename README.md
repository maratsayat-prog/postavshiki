# Postavshiki

MVP площадки для магазинов у дома и поставщиков.

Уже есть:
- каталог товаров;
- поиск и категории;
- корзина;
- кабинет поставщика;
- список заказов;
- адаптивный интерфейс;
- базовая схема данных в папке supabase.

## Запуск

Установите зависимости командой npm install, затем запустите npm run dev.

## Vercel

Создайте новый проект в Vercel, выберите репозиторий maratsayat-prog/postavshiki и нажмите Deploy. Настройки и переменные окружения на первом этапе не нужны.
